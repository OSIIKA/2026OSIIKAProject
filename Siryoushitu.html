コード資料集

Unity操作まとめ

ゲーム開発におけるUnityの操作方法をまとめた資料です。

変数（データの保存）ゲーム内の状態を保持する

変数にはpublicとprivateとSerializeFieldが存在する

①publicは他のスクリプトからアクセスできる変数

②privateはそのスクリプト内でのみアクセスできる変数

③SerializeFieldはprivate変数をインスペクターで編集できるようにするための属性

基本的にはpublic変数を減らし、SerializeFieldを使う方が推奨される

変数の型の例

①数値型

// 整数

public int hp = 100;

// 小数

public float speed = 5.0f;

// 高精度の小数

public double precisionValue = 3.141592653589793;

// 大きな整数

public long largeNumber = 123456789012345L;

②真偽値型bool（ブール型）

取得可能な値：trueまたはfalseのみ

2択の状態を示すために使用する型

public状態にしておくことで、Inspector 上にチェックボックスとして表示可能（簡単にテスト可能）

// 真偽値

public bool isGameOver = false;

if (isGameOver)

{

// ゲームオーバー時の処理

return;

}

または、void形式で以下のように記述する事もできる

public void GameOver()

{

// ゲームオーバー時の処理

}

③文字・文字列型

1文字（値型）

public char grade = 'A';

// Aキーが押されたかどうか判定する

if (key == 'A')

{

// Aキーが押された時の処理

}

文字列（参照型）

public string playerName = "Alice";

string greeting = "Hello, " + playerName + "!";

変換（char → string）

char grade = 'A';

string gradeString = grade.ToString();

変換（string → char（1文字だけ））

string name = "Alice";

char charValue = name[0];

char charValue = name[1];

長さを取得する

public int nameLength = playerName.Length;

④位置・方向

位置や方向を表すための型

public Vector3 playerPosition = new Vector3(0, 0, 0);

Vector3→3つの値（x, y, z）をまとめた型、Unityで位置・方向・速度・力などを表すときの基本型として使用されている

playerPosition→プレイヤーが「どこにいるか」「どこへ動かすか」を表す変数名として使用される事が多い

new Vector3(0, 0, 0)→x = 0, y = 0, z = 0のベクトルを表現

// 位置として使用する場合

public Vector3 enemyPosition = new Vector3(5, 0, 0);

// 方向として使用する場合

public Vector3 enemyDirection = new Vector3(1, 0, 0);
